I wanted to share  a weather conditions dataset I built for this competition using the FastF1 Python library based on earlier work by Vaibhav.
The dataset contains: lap-by-lap atmospheric readings: air temperature, track temperature, humidity, wind speed
and rainfall for all 92 race and pre-season testing sessions across 26 circuits, 2022–2025.
You can find the public dataset [here] (https://www.kaggle.com/datasets/woodshole/playground-series-s6-e5-weather-conditions/data) and the scraping code [here](https://www.kaggle.com/code/woodshole/playground-series-s6-e5-get-weather-conditions/notebook)
