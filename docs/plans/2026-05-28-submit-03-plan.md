## Goal

Ajouter **diversité architecturale** au CatBoost de submit-02 via un modèle de famille différente (Neural Net : TabPFN-3 ou RealMLP), puis stacker via LR meta sur OOF avec calibration isotonique.

> ρ(LGBM, XGB) = 0.981 → 3 GBDTs ≠ ensemble. Need NN diversity.
> — topic `defensive-pipeline-0.950-CV` (2026-05-28)

## Architecture — 3 kernels séquentiels

```
submit-02 OOF parquet ────┐
                           ├──> kernels/run_03b_stack/  ──> 03_stacked.csv
submit-03a TabPFN OOF ────┘
```

### Kernel A — `kernels/run_03a_tabpfn/`

| Setting | Value |
|---|---|
| Model | TabPFN-3 classifier from PriorLabs |
| Install | `pip install tabpfn` (open-source via HuggingFace) |
| Accelerator | `NvidiaTeslaT4` (GPU recommended for inference) |
| enable_gpu | true + `--accelerator NvidiaTeslaT4` flag |
| Features | brute base (14) + IsOriginalData flag, NO FE |
| CV | StratifiedKFold(5, seed=42) — same splits que submit-02 |
| External data | Aadi Gupta concat |

Output : `oof_predictions_tabpfn.parquet`, `test_predictions_tabpfn.npy`, score reporting per fold + per year.

**Estimated OOF AUC** : 0.951 ± 0.001 (per topic `tabpfn-3` report).

### Kernel B — `kernels/run_03b_stack/`

| Setting | Value |
|---|---|
| Input 1 | submit-02 OOF (`oof_predictions.parquet`) → upload as Kaggle dataset |
| Input 2 | submit-03a TabPFN OOF (`oof_predictions_tabpfn.parquet`) → upload as Kaggle dataset |
| Accelerator | CPU |
| Meta-learner | `sklearn.linear_model.LogisticRegression(C=1.0, random_state=42)` ou Ridge si Logistic instable |
| Calibration | `sklearn.isotonic.IsotonicRegression` sur OOF stacked → applied to test |

**Diversity gate before stacking** :
```python
rho = spearmanr(oof_cat, oof_tabpfn)
assert rho < 0.95, f"insufficient diversity (rho={rho:.3f}), abort stack"
# Per defensive-pipeline-0.950 finding: rho > 0.97 = no diversity, blend hurts
```

**Coefficient sanity check** :
```python
# Stack lr coefficients should both be positive
# Negative coef → "trust disagreement backward" = noisy model
assert lr.coef_[0] > 0 and lr.coef_[1] > 0, f"negative coef detected: {lr.coef_}"
```

## CV-LB consistency expectation

Submit-02 doit avoir établi CV-LB gap ≈ 0 (StratifiedKFold matches Kaggle test split). Donc :
- CV improvement +0.002 entre 02 → 03 stack DEVRAIT se traduire +0.002 LB
- Si LB amélioration < 50% CV amélioration → overfitting de stack
- Si LB amélioration > 150% CV amélioration → suspicieux, vérifier no-leak

## Risques & mitigations

| Risque | Mitigation |
|---|---|
| TabPFN install fail on Kaggle | Fallback RealMLP (PyTabKit), tested in yekenot notebook |
| TabPFN OOM on T4 with 627k rows | `BatchedPredicting` wrapper (batch=50_000), per topic `tabpfn-3` msg 1 |
| Diversity insufficient (ρ > 0.95) | Abort stack, ship submit-02 as final + TabPFN solo as alt |
| LR stacker overfits (coef_ negative or weird) | Try Ridge alpha=1.0, or weighted average via OOF AUC weights |
| Isotonic calibration breaks per-year sanity | Re-evaluate B7 gate after calibration ; if fail, drop calibration step |
| Stack OOF improvement < 0.001 | Marginal, not worth shakeup risk. Submit-02 = final A and B |
