> **Cible** : OOF AUC 0.949-0.952 ; LB 0.950-0.952 (vs submit-01 OOF 0.9294 / LB 0.94457)

## Goal & rationale

**Beat submit-01 LB 0.94457 par ≥ +0.005pp** via incremental FE éprouvée par discussions Kaggle.

Le baseline submit-01 a capté le signal "facile" via CatBoost native cat handling sur 14 features brutes. Pour passer 0.94 → 0.95+, **3 leviers prouvés** (post `defensive-pipeline-0.950-CV` topic 699182 + cross-validation dans notre data) :

1. **(Y,R,D) train-lookup aggregates** : 99.09% des test rows appartiennent à une unité présente dans train. Aggregates extraites du train et mergées sur train+test → +3.7pp dans le post de référence
2. **External Aadi Gupta dataset** : signal complémentaire (chronologie réelle préservée, ~8% diverge raw FastF1 mais 92% utile)
3. **Stratified random split** : élimine la pessimism de GroupKFold (CV-LB gap +1.52pp → ~0)

### Step 2 — Domain features (computed on each split)

Inspirées flexonafft (LB 0.95259), application identique aux 3 splits :

|---|---|---|

| `LapsRemaining` | `EstimatedTotalLaps - LapNumber` | Laps restants |
| `RemainingRaceProgress` | `1 - RaceProgress` | Progress inverse |
| `LapProgress_x_LapNumber` | `LapNumber * RaceProgress` | Position-progress interaction |
| `TyreAgeRatio` | `TyreLife / max(LapNumber, 1)` | Tyre wear relatif |
| `TyreLifeMinusLap` | `TyreLife - LapNumber` | Diff |
| `LapMinusTyreLife` | `LapNumber - TyreLife` | Diff inverse |
| `TyreAgeVsRace` | `TyreLife / EstimatedTotalLaps` | Wear relatif à course |
| `PitWindowPressure` | `TyreLife * RaceProgress` | "Pression pit" combinée |
| `StintPressure` | `Stint * TyreLife` | Stint avancement |
| `Is_First_Stint` | `(Stint == 1).int8` | Premier stint binaire |
| `Is_Late_Stint` | `(Stint >= 3).int8` | Late stint binaire |
| `DegPerTyreLap` | `Cumulative_Degradation / max(TyreLife, 1)` | Wear rate |

### Step 4 — Frequency encoding (sur train+test+original combiné)

Pour chaque cat ∈ {Driver, Race, Compound, Race_Year, Compound_Stint, Driver_Race, Driver_Compound, Race_Compound, Race_Compound_Stint, Compound_RacePhase, Compound_TyreLifeBin, RacePhase_TyreLifeBin, LapBin, TyreLifeBin, PositionBin} :

```python
combined = pd.concat([train[col], test[col], original[col]])
counts = combined.value_counts()
total = len(combined)
for df in [train, test, original]:
    df[f"{col}_count"] = df[col].map(counts).astype(np.int32)
    df[f"{col}_freq"] = (df[f"{col}_count"] / total).astype(np.float32)
```

**~15 cat × 2 features = 30 frequency features**.

### Step 5 — THE KILLER : (Y,R,D) train-lookup aggregates

**Architecture leak-free** :

```
for fold_idx, (tr_idx, va_idx) in StratifiedKFold(5).split(X_train, y_train):
    train_fold = X_train.iloc[tr_idx]  # 4/5 used to compute aggregates
    val_fold = X_train.iloc[va_idx]    # 1/5 receives aggregates as features

    # Step 5a — non-target aggregates : compute on train_fold (4/5)
    # → merged onto val_fold (1/5)
    # No target leak (max TyreLife, count, etc. are X-only)

    # Step 5b — target aggregates : compute target_rate on train_fold (4/5)
    # → merged onto val_fold (1/5) (out-of-fold encoding)
    # No target leak (val_fold target rate computed from train_fold rows only)

# After 5-fold pass : each train row has aggregates computed from OTHER 4 folds
# Test rows get aggregates computed from ALL train rows (since test has no target)
```

**Aggregates par (Year, Race, Driver)** — ~10 features :

| Aggregate | Formule | Type |
|---|---|---|
| `unit_max_TyreLife` | `train_rows.TyreLife.max()` | non-target |
| `unit_max_Stint` | `train_rows.Stint.max()` | non-target |
| `unit_n_rows` | `len(train_rows)` | non-target |
| `unit_LapNumber_max` | `train_rows.LapNumber.max()` | non-target |
| `unit_LapNumber_min` | `train_rows.LapNumber.min()` | non-target |
| `unit_LapTime_mean` | `train_rows["LapTime (s)"].mean()` | non-target |
| `unit_LapTime_std` | `train_rows["LapTime (s)"].std()` | non-target |
| `unit_PitStop_any` | `train_rows.PitStop.max()` (=any) | non-target |
| `unit_PitStop_sum` | `train_rows.PitStop.sum()` | non-target |
| `unit_PitNextLap_mean_OOF` | `train_rows.PitNextLap.mean()` | **target** (k-fold) |

**Aggregates par (Year, Race, Driver, Stint)** — ~8 features :

| Aggregate | Formule | Type |
|---|---|---|
| `stint_max_TyreLife` | (Y,R,D,S) groupby | non-target |
| `stint_n_rows` | count | non-target |
| `stint_PitStop_any` | max(PitStop) | non-target |
| `stint_RaceProgress_min` | min | non-target |
| `stint_RaceProgress_max` | max | non-target |
| `stint_LapNumber_min` | min | non-target |
| `stint_LapNumber_max` | max | non-target |
| `stint_PitNextLap_mean_OOF` | mean | **target** (k-fold) |

**Fallback** :
- Test rows où (Y,R,D) absent du train : 0.91% des rows → fill NaN (CatBoost handles natively)
- Test rows où (Y,R,D,Stint) absent mais (Y,R,D) présent : 7.21% → fill stint_* avec unit_* equivalents
- Test rows où ni (Y,R,D) ni (Y,R,D,Stint) : fill avec global mean (rare, <1%)

**Total aggregate features : ~18.**

## Risques & mitigations

| Risque | Mitigation |
|---|---|
| (Y,R,D) aggregates leak (target encoding pas leak-free) | Strict k-fold OOF computation, jamais aggregate from train_val into train_val |
| Aadi Gupta data hurts OOF (per `submission-generalization-LB` topic) | OK, monitor LB > OOF gap. Si OOF baisse mais LB grimpe → garder. Si les deux baissent → exclure |
| CatBoost params trop agressifs (depth=8 + iter=11000 → overfit) | early_stopping=500 protège. Si best_iter ~max sur tous folds → diverge, baisser depth ou augmenter l2_leaf_reg |
| Kernel timeout (5 folds × 40 min = 200 min, sous 12h mais marge) | iterations=11000 cap, early_stop=500 → realistic best_iter ~2000-5000 → ~30 min/fold. Si > 1h/fold, baisser iterations cap |
| OOM Kaggle (32 GB) | ~93 features × 627k rows × float32 ≈ 235 MB → OK. CatBoost CPU mode utilise ~3-5 GB par model. 5 séquentiels, pas en parallèle |
| 2023 collapse (per-year AUC < 0.85) | Gate B6 catch. Si trigger, ajouter Year-spécifique sample_weight ou fold stratify par (target × Year) |
